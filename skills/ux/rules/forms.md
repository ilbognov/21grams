# 21g UX · Forms and input

House default. When the project has its own patterns, express this through its components and flows (SKILL.md, rule zero).

## Laws
Full law, how to apply it and what to flag: `references/laws.md`.

- **A7** Postel's Law: accept messy formats and echo a clean value; stay strict on security and data integrity.

## Rules
Full rule, how to apply it and what to flag: `references/rules.md`.

- **#12** Drafts and unfinished input save automatically, so going back doesn't erase them.

## Field rules
Learned from real passes: `references/field-rules.md`.

- **F15** Inline edits save themselves.
- **F26** Waits and cooldowns live on the control; confirmations echo the input.
- **F48** One picker for add and edit.
- **F49** Immediate on/off settings are toggles.
- **F56** Time-bound actions ask for a from–to range and show its length.
- **F63** Typing never lags or resets because of background updates.
